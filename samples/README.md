# Sample documents

> ⚠️ **Every document in this folder is FICTITIOUS.** People, companies, addresses, RFC/CURP,
> ID numbers, accounts and amounts are invented. No logos, photos, QR codes, barcodes,
> seals or digital signatures are reproduced. Each page carries the footer
> `DOCUMENTO DE PRUEBA - DATOS FICTICIOS`.

These PDFs are generated by [`scripts/generate_samples.py`](../scripts/generate_samples.py). They are used by the integration tests and for manual testing (Swagger, `documentUrl`).

## Golden files
Each sample has a golden file at `expected/<name>.json`. It records:
- the expected category, type and extraction path (`full`, `retrieval` or `skip`);
- the page count;
- the key fields:
  - `fields`: exact match;
  - `contains`: substring match;
  - `counts`: list lengths.

The comparison ignores accents, case, whitespace, commas and `$`.

## Regenerate
```powershell
uv run python scripts/generate_samples.py
```
Generation is deterministic. After changing the generator, run both test suites:
```powershell
uv run pytest
uv run pytest -m integration
```
